$xoopsOption['template_main'] = 'x.tpl' inside a function or method writes a local array unless the function declares global $xoopsOption. The page then renders without its template, and a read is an undefined variable.

The fix writes $GLOBALS['xoopsOption']. Script-level code already runs in the global scope and is not reported, nor is a function that declares the global or takes $xoopsOption as a parameter.
