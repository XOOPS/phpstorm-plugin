file_exists($x) and is_readable($x) are true for a directory. When the condition's body then includes $x or reads it with readfile(), file_get_contents(), fopen() or similar, a directory name reaches the reader.

The fix appends && is_file($x): it only narrows the condition. A negated check (!file_exists($x)) is reported without a fix, because !a && b would invert it.
