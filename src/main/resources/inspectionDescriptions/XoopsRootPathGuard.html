Include-only PHP files (classes, preloads, includes, blocks) start with 
defined('XOOPS_ROOT_PATH') || exit('Restricted access');

A file that bootstraps the core itself — any top-level require of mainfile.php, header.php, cp_header.php, admin_header.php, print.php … — is a public entry point and is never reported, even when error_reporting() or flag assignments precede that require. preloads/autoloader.php, language files, tests, 404 stubs and fully qualified \defined() guards are recognised.

The quick-fix inserts the guard after namespace / declare and before use or the class docblock, on its own line.
