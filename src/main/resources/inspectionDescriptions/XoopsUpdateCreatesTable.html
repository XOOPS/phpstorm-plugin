A CREATE TABLE in sql/mysql.sql that no update path mentions is never created for a module that is already installed. If a released version shipped without the table, sites updating from it fail with error 1146 on first use. Whether such a version exists cannot be told from the tree, and a table as old as the module needs no update path, so this is a weak note.

Update paths searched: onupdate.php, include/onupdate.php, include/update.php, include/install.php and every YAML under sql/. An update that re-runs the SQL file or calls createMissingTables() / synchronizeSchema() covers every table. Modules without any update callback are not reported, nor is an SQL file the installer never runs: no active $modversion['sqlfile'] (commented out or false) and no install callback that reads mysql.sql itself.

Report only: the idempotent create (table-exists check, migrate YAML) belongs to the author.
