A file under preloads/ runs inside every module's request. Assigning $xoopsModule or $xoopsModuleConfig there (or declaring them global, the prelude to it) repoints every later reader on the page to the wrong module: "Division by zero", null config keys, in a module that has nothing to do with the preload. Inside a function, $xoopsModule = … is a local unless the function declares it global; $xoopsModule = $GLOBALS['xoopsModule'] ?? null; is a read and is not reported.

Report only. Load the preload's own config into a local: $cfg = xoops_getHandler('config')->getConfigsByCat(0, $mod->getVar('mid')).
