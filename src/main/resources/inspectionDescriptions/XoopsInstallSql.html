Rules on modules/x/sql/*.sql, the file $modversion['sqlfile'] points at.

  • FOREIGN KEY … REFERENCES: SqlUtility::prefixQuery() prefixes only the table being created, never the REFERENCES target. The key dangles to a nonexistent table; a plain INSERT fails with 1452, an INSERT IGNORE silently writes nothing. Enforce the relation in the handler, or add the key in oninstall.php with $db->prefix().
  • Hard-coded prefix: xoops_, {prefix} and %s are not installer tokens; the installer adds the site prefix itself. Use the bare module table name.
  • ENGINE=MyISAM (weak): no transactions, no row locks; create module tables with InnoDB, which supports FULLTEXT since MySQL 5.6. Not reported on the core installer schema (install/sql/), which keeps its legacy tables MyISAM on purpose.

Report only: each change alters the schema and belongs to the author.
