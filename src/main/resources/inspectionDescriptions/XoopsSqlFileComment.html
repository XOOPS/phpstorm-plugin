A line that is exactly -- is not a comment for SqlUtility::splitMySqlFile(); only -- (dash dash space) and # are. The bare line stays glued to the next statement, prefixQuery() fails its ^CREATE TABLE match and the installer skips that table with no error.

One finding per line. The fix inserts the space on that line only, re-checking the live line text, so it is safe in any batch order. The same defect is also reported on xoops_version.php by "Bare -- comment in the SQL file".
