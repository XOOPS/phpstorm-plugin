A switch ($op) branch that writes (handler insert / delete, exec(), file writes) without a CSRF token check.

A branch is covered by its own $GLOBALS['xoopsSecurity']->check() or xoops_confirm() (directly or through a function of the same file that checks and stops), by a top-level gate before the switch, or by an if (!$GLOBALS['xoopsSecurity']->check()) before it that exits or resets $op for the branch's value: if (in_array($op, ['save', 'delete'])) { if (!…->check()) { … } }. A gate behind any other condition, in an else or a loop covers nothing; a gate that only runs for POST covers nothing when $op is read from GET and the GET path still reaches the switch. The branch content decides, never the case label.
