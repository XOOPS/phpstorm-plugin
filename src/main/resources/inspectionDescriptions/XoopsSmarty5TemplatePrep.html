Constructs that work on Smarty 4 but need rework before a Smarty 5 core: bare <{parent}> / <{child}>, <{insert}>, <{make_nocache}>, config_load scope=, and PHP functions used as modifiers (|substr, |trim, |strtolower …), which Smarty 5 only accepts when registered.

Off by default: enable it for a tree that is being prepared for Smarty 5. There is no quick-fix.
