<{xoAdminIcons home.png}>: since Smarty 3 (XOOPS 2.5.11) a bare plugin argument is parsed as an expression and the template does not compile.

The fix quotes it: <{xoAdminIcons 'home.png'}>. Single quotes are used everywhere, also inside a single-quoted HTML attribute, because Smarty removes the whole tag before the browser sees it and most compiler.xo*.php plugins strip only '.

Not reported on cores older than 2.5.11, where the argument had to be bare.
