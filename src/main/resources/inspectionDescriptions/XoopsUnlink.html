unlink($path) with no is_file() / file_exists() on the same expression dominating it. A check in the enclosing if or a preceding early-exit counts, at any block level up to the function, and also inside a previous try whose every catch exits as well. break / continue count as an exit. Also accepted: a $this->exists()-style helper of the same class whose body checks the same $this->… path; a check on $x when the unlinked path is realpath($x); and if (false === file_put_contents($p, …)) return; (or touch()): the code created the file itself. An SplFileInfo object's isFile() counts when its getRealPath() or getPathname() is unlinked, directly or through a variable (a DirectoryIterator loop), and its isLink() counts when getPathname() (the link itself) is unlinked. A check behind an unrelated && (if ($a && !is_file($p)) return;) does not count, because a false $a skips it; nor does isFile() before getPath() (the containing directory) or isLink() before getRealPath() (the link's target).
