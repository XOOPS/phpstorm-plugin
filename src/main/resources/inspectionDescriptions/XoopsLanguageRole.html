Language catalogs: _MI_ in modinfo.php, _AM_ in admin.php, _MD_ in main.php, _MB_ in blocks.php, _CO_ in common.php.

A canonical file with a foreign prefix gets one note per constant. A non-canonical file (modinfo1.php, a backup copy) gets one file-level note, unless some code loads it by name (xoops_loadLanguage('cpanel', 'system')).

Only a module's own catalogs directly under language/<lang>/ are checked: the core's htdocs/language/, the Frameworks/ libraries (moduleadmin ships a xoops_version.php but loads its main.php by path) and sub-catalogs such as language/<lang>/admin/<page>.php follow their own loaders. _MD_AM_ (system) and _MD_A_ (Protector, D3) are admin constants by name and belong in admin.php.
