Smarty 5 removed assignByRef(), appendByRef(), the register_*() family and the public template_dir / compile_dir properties, and has no global \Smarty class (core 2.8 templates are \XoopsTpl, which extends \Smarty\Smarty).

assignByRef($k, $v) → assign($k, $v) is offered only when $v is never written again in its scope — then by-reference and by-value assignment are the same thing. Everything else is reported for a hand rewrite.

Smarty 5 ships with core 2.8: on a 2.5 / 2.7 tree (Smarty 2 / 4, detected from include/version.php or the Core Version setting) these calls are the current API and nothing is reported. A standalone module without a core is checked.
